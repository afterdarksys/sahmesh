# sahmesh implementation plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The contract is `~/development/systemapi.io/docs/sah-mesh-protocol.md`; the design is `2026-10-22-sahmesh-design.md` beside this file. Read `~/development/ads-fable-utils/SECURITY-RULES.md` first. Every security-domain file carries a `Threats:` header and negative tests.

**Goal:** A loopback SOCKS5 proxy (`sahmesh up`) that reaches any SystemAPI host by `NAME.sah:PORT` over one multiplexed `mesh:open` WebSocket per host, with the server side wired end to end and the agent untouched.

**Architecture:** Server: a `mesh.js` session wrapper whose streams are ordinary `TcpChannels` sessions behind a per-stream client view object; `mesh:open` is a new operator scope and ticket purpose. Client: Go module `github.com/afterdarksys/sahmesh` with `internal/mesh` (mux, credit both ways), `internal/socks` (SOCKS5, CONNECT only), `internal/routes`, and sahlink's copied `client`/`config`/`token`/`secfile`/`target`.

**Tech stack:** Node (existing `ws`, `node:test`), Go 1.26 (`github.com/coder/websocket`, `github.com/BurntSushi/toml`).

Two lanes run in parallel: **S** (server, in `~/development/systemapi.io`) and **C** (client, in `~/development/sahmesh`). **D** (docs) follows. Do not commit; the owner commits.

### S3: `tcp.js` split

**Files:** Modify `playground/tcp.js`. Test: existing `tests/tcp.test.js` stays green.

Split `open(ws, parsed, hostId)` into the upgrade-path checks (ticket, target from the ticket, signer, re-check, agent, caps) and `startSession(client, opts)` where `opts = { hostId, tenantId, actor, auth, target, purpose = 'tcp:open', mesh = null, stream = null, clientEof = false, encode, clientCredit, onSent }`. `startSession` builds `s`, the sink and source, the lease, `tcp_open`, timers, and returns `s`. The per-socket path calls it with the real `ws`. Behaviour for `tcp:open` is unchanged.

Session additions: `s.purpose`, `s.mesh`, `s.stream`. `renew()` re-checks with `s.purpose` (scope) and `{ target: s.target }` (policy; `policyDecision` handles both purposes). `tcp_start` / `tcp_end` payloads add `mesh` and `stream` only when `s.mesh` is set. `liveFor` stays the single counter: mesh streams are in `this.sessions`, so caps are shared for free.

Client view contract (what `startSession` calls on `client`): `readyState`, `bufferedAmount`, `send(data)` (Buffer or string), `close(code)`, `pause()`, `resume()`, `isPaused`. `ws.on(...)` handlers stay in the per-socket path only.

### S5: `mesh.js` streams, frames, credit

**Files:** `playground/mesh.js`. Test: `tests/mesh.test.js`.

Client message handling (`ws.on('message')`): binary → first 4 bytes BE id; text → JSON object with `type`. Apply §3.2 exactly:

- before `ready`: any frame → `protocolError(session)`.
- `mesh_open`: `stream` integer in `[1, 2^32-1]` and `> lastId` else protocol error; set `lastId`. `validateTcpTarget(target)`: `bad_target`/`target_forbidden` → `mesh_status` error for that stream (stream not created, but the id is spent). Then `policyDecision(registry, hostId, 'tcp:open', {target})` → `target_denied` as a stream error. Caps: `tcp.liveFor(actor) >= perActor` or `tcp.liveFor(agent) >= TCP_PER_AGENT` → `cap_reached`. Then create the view and call `fm.tcp.startSession(view, {...})`; entry = `{ id, view, session, toClient: new CreditStream({window}), fromClient: new CreditStream({window}), clientEof:false, connected:false }`.
- binary for id: `id > lastId` → protocol error; entry missing (closed) → ignore; `!entry.connected || entry.clientEof` → protocol error; `fromClient.receive(n)` false → protocol error (`credit_overrun`); else `fm.tcp.onClientMessage(entry.session, buf, true)`.
- `mesh_eof`: entry missing → ignore; set `clientEof`; forward `tcp.onClientMessage(entry.session, Buffer.from('{"type":"tcp_eof"}'), false)`.
- `mesh_close`: entry missing → ignore; `tcp.end(entry.session, 'client_closed', {notifyAgent:true})` (no frame to the client).
- `mesh_credit`: entry missing → ignore; `creditBytes(msg)` null or `toClient.grant(n)` false → protocol error; else `entry.session.sink.pump()`.

The view object per stream: `readyState` = client ws readyState; `bufferedAmount` = client ws bufferedAmount; `send(data)`: Buffer → `ws.send(Buffer.concat([idBE, data]))`; string → parse, rewrite `tcp_status`→`mesh_status`, `tcp_eof`→`mesh_eof`, `tcp_close`→`mesh_close`, add `stream`, send; on `mesh_status` with `payload.status === 'connected'` set `entry.connected = true`; on `mesh_close` or a `mesh_status` error delete the entry and re-arm the idle timer if no streams remain. `close(code)`: delete the entry (the real socket stays open). `pause()`/`resume()`: no-ops (credit replaces them); `isPaused`: false.

`startSession` opts for a mesh stream: `encode: (chunk) => Buffer.concat([idBE, chunk])`, `clientCredit: entry.toClient`, `onSent: (n) => { const c = entry.fromClient.drain(n); if (c > 0) sendJSON(ws, {type:'mesh_credit', stream:id, bytes:c}); }`, `purpose: 'mesh:open'`, `mesh: session.id`, `stream: id`.

Client ws close: every live stream `tcp.end(s, 'client_closed', {notifyAgent:true})`; `mesh_end` row with reason `client_closed`. Agent gone: streams get `agent_disconnected` (tcp's `onAgentGone` already does this since they are in `tcp.sessions`); then the session ends `agent_disconnected`.

Session re-check every 30 s: `recheckChannelTicket(registry, {actor,tenantId,auth,hostId}, 'mesh:open', null)`; `'internal'` → skip; any denial → end streams `stopped`, session `stopped`.

### C4: `internal/mesh` session

**Files:** Create `internal/mesh/session.go`, `internal/mesh/stream.go`, `internal/mesh/session_test.go` with a fake server (`net/http/httptest` + `coder/websocket`) that speaks the contract.

`Dial(ctx, wsURL, httpClient, Options) (*Session, error)`: opens the socket, `SetReadLimit(maxPayload + 4)`, waits ≤ 30 s for `mesh_ready` (anything else → `protocol_error`), starts the read loop. `Session.Open(ctx, host string, port int) (*Stream, error)`: next id (`atomic` counter starting at 1), sends `mesh_open`, waits for `connected` (success) or a stream `mesh_status` error (`*StatusError{Code}`), 30 s handshake timeout → `connect_timeout`. `Stream` implements `net.Conn`: `Read` from a bounded inbound queue fed by the read loop (never more than `window` outstanding: a server overrun is a session `protocol_error`), returns credit via `mesh_credit` as `Read` drains (batched by `Credit.Drain`); `Write` blocks on send credit (cond var), splits at 64 KiB, refuses after `CloseWrite`; `CloseWrite` sends `mesh_eof`; `Close` sends `mesh_close` unless the stream already ended, and unblocks readers and writers. The read loop: binary for an unknown id → `protocol_error` if id > last opened, else ignored; `mesh_eof` → readers see EOF after queued bytes; `mesh_close` → `Closed()` with the reason, readers get EOF (reason `closed`) or `*StatusError` otherwise; `mesh_credit` → grant (overflow → `protocol_error`); session `mesh_status` error / `mesh_end` / socket error → every stream fails with that code and `Session.Done()` closes. `protocol_error` from the client side closes the socket with 1002 and fails everything.

Tests (against the fake server): two streams interleaved carry distinct bytes both ways; a stream error leaves the other stream alive; server data past the window is `protocol_error`; the client never sends past its credit (fake server asserts) and resumes after `mesh_credit`; `CloseWrite` → `mesh_eof` and reads continue; `mesh_eof` from the server → `Read` EOF; ids strictly increase; late frames for a closed id are ignored; `mesh_end` fails open streams with its reason; the WebSocket URL and ticket never appear in any error string.

### C6: `internal/socks`

**Files:** Create `internal/socks/socks.go`, `internal/socks/resolve.go`, `internal/socks/socks_test.go`.

RFC 1928 server for one accepted `net.Conn`: version 5, methods must include `0x00`, reply `05 00`; else `05 FF` and close. Request: CONNECT (`0x01`) only; BIND/UDP → reply `0x07`. ATYP `0x01` IPv4, `0x04` IPv6, `0x03` domain (length-prefixed, ≤ 253). `Resolve(dest) (agent string, targetHost string, err)`: domain → must end in `.sah`, label before it passes `client.ValidHostName`; else `ErrNotAllowed`. IP → `routes.Lookup`; miss → `ErrNotAllowed`; `target.Check(ip.String())` also runs locally (loopback and refused classes give `ErrNotAllowed`). Reply codes per contract §16; success reply `05 00 00 01 00 00 00 00 00 00`. Timeouts: 10 s to finish the handshake. `Serve(ctx, ln, dial func(ctx, agent, host string, port int) (net.Conn, error))` with the loopback-only `CheckBindAddr` copied from sahlink's `forward/listen.go` (accept `127.0.0.1` and `::1`; refuse `localhost`, `0.0.0.0`, `::`). After CONNECT succeeds: bidirectional copy, `CloseWrite` propagation, close both on either error.

Tests with a real SOCKS5 client (write bytes by hand): no-auth handshake; `web1.sah:5432` dials agent `web1` target `local`; `10.0.0.7:3389` with route `10.0.0.0/24=gw1` dials `gw1` target `10.0.0.7`; `example.com` → `0x02`; `localhost` → `0x02`; `127.0.0.1` → `0x02`; `169.254.169.254` → `0x02`; UDP ASSOCIATE → `0x07`; auth-required-only client → `FF`; a dial error `connect_refused` → `0x05`; bytes relay both ways; `CheckBindAddr("0.0.0.0")` refused.
